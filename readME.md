Template for organizing the semester-long machine learning project for CS279 Fall 2026 at St. Olaf.

The data directory houses all your data- original csv, data that you clean during step2 and then save as a csv. This can also house a data dictionary (feel free to organize in a markdown file)

The code directory houses all your code- you can split your pipeline into various .py or .ipynb files. I'd recommend having three: one for EDA, one for data cleaning, and one for modeling.

The assets directory houses various images created. This can be graphs created during EDA, or model evaluation during the modeling step. 

You can also upload a slide deck, create a dashbord, or have a report in the main portion of this. You can even use this repo to create a website using [Quarto](https://quarto.org/docs/websites/)! 

Feel free to remix and reorganize this template as you see fit! If you want to use this repo on your portfolio, you'll want to update readME.md to be a walkthrough of your project.
