## Welcome!
Template for organizing the semester-long machine learning project for CS279 Fall 2026 at St. Olaf. Make sure to fork this. You can click on Code > Codespace > start codespace on main to view your repo in the browser in a VSCode-like IDE. Commit changes as usual. Ask Prof Kim if you have any questios on how to get started.

## Organization
The data directory houses all your data- original csv, data that you clean during step2 and then save as a csv. This can also house a data dictionary (feel free to organize in a markdown file)

The code directory houses all your code- you can split your pipeline into various .py or .ipynb files. I'd recommend having three: one for EDA, one for data cleaning, and one for modeling. You can add notes to yourself using multiline comments (three quotes surround your text) or single line comments (single hashtag followed by a thought/note)

The assets directory houses various images created. This can be graphs created during EDA, or model evaluation during the modeling step. 

The requirements.txt is important as this is where we can ensure modules and dependencies are taken care of.

## What else you can do with this
You can also upload a slide deck, create a dashbord, or have a report in the main portion of this repo. You can even use this repo to create a website using [Quarto](https://quarto.org/docs/websites/)! 

Feel free to remix and reorganize this template as you see fit! If you want to use this repo on your portfolio, you'll want to update readME.md to be a walkthrough of your project.
